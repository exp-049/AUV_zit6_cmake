# 工程文档

文档按用途分为以下目录：

- [`architecture/`](architecture/)：工程架构说明及文档源文件。
- [`protocols/`](protocols/)：与 VIT6、上位机及节点通信相关的协议。
- [`hardware/`](hardware/)：深度传感器、组合导航等硬件手册。
- [`configuration/`](configuration/)：推荐配置文件。
- [`guides/`](guides/)：构建、启动和上位机操作示例。

## 主要入口
